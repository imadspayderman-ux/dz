# Hyper Garage 3D — معرض سيارات تفاعلي ثلاثي الأبعاد

موقع سيارات ثلاثي الأبعاد بواجهة احترافية. اختر سيارتك بالفأرة، اضغط على
زر التسريع في لوحة المفاتيح، فتسمع صوت محرّك السيارة الخاص بنوعها (V8، V12،
V10، I4 توربو، W16، EV…) مع توربو، ومكابح، وبوق سيارة، وأضواء، وكاميرات
متعددة الزوايا.

## المميزات

- **12 سيارة واقعية** مختلفة الأشكال والألوان والعجلات والأجنحة (عضلية،
  سوبر، GT، EV، رالي، رودستر، W16، …).
- **محرك صوت احترافي** مبني على Web Audio API يولّد صوت كل محرك لحظياً:
  - ترددات الإشعال حسب عدد الأسطوانات.
  - تردّدات أساسية وتوافقيات مخصّصة لكل محرك (V8 ذو الصوت العميق،
    V12 الصاخب، V10 الحاد، …).
  - سحب التوربو (Turbo whistle) مع تأخّر دوران (Lag).
  - صفير الشاحن العلوي (Supercharger whine) لسيارات الـ SC.
  - فرقعات على Overrun (لما ترفع رجلك من الدعسة في الـ RPM العالي).
  - صرير المكابح (Brake squeal).
  - بوق السيارة بنغمتين متناغمتين.
  - وضع كهربائي خاص للسيارة الـ EV (whine بدلاً من احتراق).
- **مشهد شو-روم ثلاثي الأبعاد** مع منصة دوّارة، إضاءة احترافية، ظلال،
  انعكاسات على هيكل السيارة ودسكات الفرامل.
- **تحكم كامل بالفأرة ولوحة المفاتيح** + شاشة HUD حيّة (RPM، السرعة،
  التوربو، الناقل).
- يعمل بالكامل في المتصفح بدون أي خوادم أو ملفات صوتية ضخمة.

## التشغيل محلياً

لأن المشروع يستخدم ES modules، يجب تشغيله من خلال خادم HTTP محلي (لا
يكفي فتح الملف مباشرة):

```bash
cd hyper-garage-3d
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/
```

> أول مرة تضغط على **«دخول المعرض»** يبدأ تشغيل الصوت — هذا مطلوب من
> المتصفحات (سياسة AudioContext).

## التحكم

| المفتاح | الوظيفة |
|---|---|
| الفأرة | اختيار السيارة + تدوير الكاميرا حول المنصة |
| `W` أو `↑` | تسريع (Accelerate) |
| `S` أو `↓` | مكابح (Brake) |
| `Shift` | توربو (Turbo Boost) |
| `H` | بوق السيارة (Horn) |
| `L` | تشغيل الأضواء الأمامية |
| `C` | تبديل زاوية الكاميرا (orbit / front / side / rear / top) |
| `←` / `→` | السيارة السابقة / التالية |

## الملفات

- `index.html` — هيكل الواجهة + HUD + قوائم.
- `styles.css` — التصميم الزجاجي (glass) للواجهة.
- `js/main.js` — نقطة الدخول وحلقة اللعبة.
- `js/scene.js` — مشهد Three.js (الإضاءة، الأرضية، المنصّة).
- `js/carBuilder.js` — مولّد سيارات إجرائي (Procedural).
- `js/cars.js` — كتالوج السيارات والملف الصوتي لكل محرك.
- `js/audio.js` — مولّد أصوات المحرك في Web Audio.

## ملاحظات تقنية

أصوات المحرك مولّدة برمجياً (Procedural) بدلاً من استخدام ملفات صوتية،
لكن نتيجة الـ pipeline (أوسليتورات بسوائل توافقية + ضوضاء مفلترة + Turbo
whistle + crackles + brake squeal) تعطي إحساساً واقعياً جداً يستجيب
مباشرة للدعسة وللتوربو ولـ RPM. هذا يجعل الموقع خفيفاً جداً (لا توجد
ملفات صوت بحجم ميغابايتات) ويعمل offline.
